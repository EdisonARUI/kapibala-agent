# 意图识别模块 (Intent Module) - 技术文档

## 概述

意图识别模块 (Intent Module) 是获客初筛 Agent 的核心 AI 大脑。它的唯一职责是：阅读用户的历史聊天上下文，理解客户意图，并评估客户的当前情绪状态，为后续的流程提供非结构化的判定依据。

## 2. 核心功能

### 2.1 上下文构建 (Context Builder)
- 从底层的状态存储中提取 `messages` 列表。
- 可能需要对上下文进行裁剪（例如：只保留最近的 10 轮对话）以节省 Token 并在长上下文中保持专注。

### 2.2 System Prompt 管理
- 提供强大且严格的 System Prompt，要求大模型仅做“观察者”和“分析师”，此时**不负责生成回复**。
- Prompt 中明确列出意图的枚举定义（如：`interested`, `needs_info`, `rejected`, `irrelevant`, `escalate_to_human`, `other`）以及情绪的判定标准。
- Prompt 限制了大模型只做识别分析，不产生实际客户回复。

### 2.3 LLM 调用引擎
- 支持调用 OpenAI (GPT-4o)、Anthropic 或国产大模型接口。
- 强制开启 `response_format={ "type": "json_object" }`，促使模型输出结构化的分析结果。

---

## 3. 输入与输出

**输入 (依赖 State)：**
- `messages`: 包含 System Prompt 以及 User/Assistant 的历史对话。

**输出 (非结构化/半结构化数据)：**
- 一个 JSON 字符串，例如：
```json
{
  "intent": "needs_info",
  "is_unhappy": false,
  "reasoning": "用户正在询问产品价格，态度正常"
}
```

注意：意图识别模块不处理异常重试，所有的强类型验证与纠错交给“解析模块 (Parsing Module)”。
