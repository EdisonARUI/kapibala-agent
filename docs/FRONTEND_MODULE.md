# 前端模块 (Frontend Module) - 技术文档

## 概述

前端模块 (Frontend Module) 是获客初筛 Agent 系统的交互层。它的主要职责是接收用户的自然语言输入，并向用户展示 Agent 的回复与当前状态。在 MVP 阶段，它可以是一个最简命令行交互 (CLI) 界面，也可以使用 Gradio/Streamlit 快速搭建的 Web 原型。

## 2. 核心功能

### 2.1 会话管理
- 初始化并维护用户的会话 ID (Session ID)。
- 在 Web UI 中展示历史聊天记录 (`messages`)。

### 2.2 交互反馈
- 支持展示 Agent 的“思考中”状态。
- 如果采用流式输出 (Streaming)，负责逐字/块渲染大模型的回复内容。
- 当触发转人工 (`is_escalated == True`) 时，在界面上给出明确的系统提示（例如：“已为您接入人工客服，请稍候”）。

### 2.3 防御反馈拦截
- 捕获来自防御模块 (Defense Module) 的速率限制错误（如 HTTP 429），并友好地提示用户（例如：“您的发送频率过快，请稍后再试”）。

---

## 3. 数据流转

1. **输入**：用户输入文本。
2. **发送**：将文本与 Session ID 发送给底层的调度引擎。
3. **等待/接收**：监听流式事件或等待同步返回。
4. **渲染**：如果是普通 `reply` 动作，则将回复追加到聊天窗口；如果是后台动作（如 `mark_not_interested`），则根据系统设计决定是否渲染后台提示。
